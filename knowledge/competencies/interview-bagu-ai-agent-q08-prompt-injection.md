# 如何设计防止 Prompt 注入攻击的系统？

源题解析：Prompt 注入是 LLM 应用的重要安全问题，AI Agent 岗位会考察安全意识。

源题考察点：直接注入 vs 间接注入的区别；深度防御而非单点防护；Agent 中工具权限最小化原则。
