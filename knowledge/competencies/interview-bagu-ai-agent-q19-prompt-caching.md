# 什么是 Prompt Caching？如何在工程中最大化缓存命中率？

源题解析：Prompt Caching 是 LLM 成本优化的重要手段，AI Agent 工程师必须掌握。

源题考察点：缓存的命中条件（前缀必须完全相同）；费用计算（写入 vs 命中的差异）；在对话系统中保持缓存有效的设计。
