# 如何实现 Agent 的记忆系统？短期记忆、长期记忆、Episodic Memory 有什么区别？

源题考察点：四类记忆的存储机制和检索方式；记忆写入的时机和异步处理；记忆的更新/遗忘策略（避免记忆无限增长）。
