## 准备

技术段前 15 秒展示 cards.json 中原题、考察点和核验正文，随后 25 秒展示 SGD/AdamW 跳过 mini 与小 batch 归一化重排的实际记录，接着 10 秒显示 12 条查询对照，最后 10 秒说明实际引用与候选人证据分开。记录标注“2026-09-08，合成查询，真实模型历史记录”。不要把检索命中率称作能力评估准确率。

- 使用一个信息技术主岗位和一份完整 JD。提前跑通实际模型会话，保留可展示的完整记录。
- 真实模型、确定性 Demo 与历史回放标记清楚。剪辑等待不会改变真实问答顺序。
- 仓库地址：`https://github.com/lux-666/better-resume`。2026-09-09 已确认为公开仓库，源码从 GitHub Release 下载。
- 使用脱敏资料，不把 API 密钥或真实候选人数据录入视频。
- 画面建议 1920×1080。放大原话和报告，保证字幕可读。

## 提交检查

完整观看成片，确认 3–5 分钟时长、画面与解说清楚，仓库地址正确。成片与源码说明共同展示本地体验；赛事是否接受这种交互交付方式仍需主办方确认，不自行把 GitHub 链接当成已满足所有入口条款。
